# DPI Gaming Tweaker

แอป Android สำหรับปรับ DPI/ความละเอียด และตั้งค่าเพิ่มประสิทธิภาพเกม (ผ่าน Shizuku หรือ Root)

- Build อัตโนมัติด้วย GitHub Actions (แท็บ **Actions** > รอเครื่องหมายถูกสีเขียว > ดาวน์โหลด Artifact `DpiGamingTweaker-apk`)
- ติดตั้ง `app-debug.apk` ต้องอนุญาตการติดตั้งจากแหล่งที่ไม่รู้จัก
- ต้องติดตั้งแอป **Shizuku** แล้ว Start ก่อนใช้งาน (หรือมือถือ Root)
